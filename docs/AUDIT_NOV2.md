# Code audit of Nov 2, 2026: what was found, what changed, what is open

Six independent read-only reviews (training harness and launchers; the agent loop; ensembles, evaluation and analysis scripts; samplers, acquisition and registry; the dispatcher and cluster workflow; a repository outline) ran against the local checkout and, read-only, the cluster. Findings were kept only when verified by a code trace, a small measurement or inspection of real outputs. "Fixed" means changed and deployed on Nov 2, with a test where one is possible without a GPU. Nothing below that is marked "open" has been changed. Companion documents: `CODEBASE_OUTLINE.md`, `CLEANUP_PLAN.md`.

The headline numbers survive: the stacks use no test labels anywhere, the test sets are bit-identical across 1,110 of 1,111 label files, the nested pools are exact prefixes, and more than 25 headline numbers in `TUNED_LEGNET.md`, `STUDY_LOG_OCT29_NOV2.md` and `LEGNET_VS_LOOP_AND_NEXT_ARMS.md` recomputed to four decimals. The issues are in the SNV effect, in some reservoirs, in how the loop was run, and in how the running system is stored.

## 4. Repository hygiene (details and commands in `CLEANUP_PLAN.md`)

README, ARCHITECTURE and ONBOARDING describe a Hydra benchmark that no longer exists (26 cited files and 6 cited docs are missing); `pytest tests/ -q` aborts with 6 collection errors (with those excluded 481 pass, 3 fail); `albench/registry.py` and `paths.py` are 16-line shims that AGENTS.md tells people to edit; 108 tracked files hard-code the cluster path (two in `albench/`); the LegNet bank needs `external/human_legnet/model.py`, which is git-ignored; about 115 dead files; about 2,500 lines of unregistered sampler modules; the CLI `albench screen` crashes on a removed strategy name; `ALLoop` raises `UnboundLocalError` when both a provider and a pool are given; `batchbald_binned` saturates after 2 picks without a warning (no reported result uses it); several parameters are declared but ignored (mutagenesis `normal` ignores `mutation_rate`; evoaug `p_*` are weights; `ise` target mode always targets 0.0).

## Checked and found correct

Flank constants and orientation; the wide window, `WideCrop` and RC equivariance for every shift in +-10; encoders agree on 200-bp input; OneCycle step counts; EMA formula; validation and test alignment on 256 models (recomputed r equals the stored r to 1e-4); all test labels stamped `oracle_v3` with no NaN; `D` equals the pool size in all 470 loop configs; no test label enters any selection; no silent Muon fallback; coordinator parsing matched in 422 of 422 plans and plan-to-model linkage is consistent; no proposer or coordinator call was paid twice across 423 round logs; prompts contain validation numbers only (no 4-decimal test r of the 829 models appears in a prompt); no exploded prediction slipped through (max |pred| 13.7 over 740 models); chromosome holdouts in `bg_cache` and the canonical `k562_nested` pools; the Ti/Tv knob realises 1.001, 2.008 and 4.026 for requested 1, 2 and 4; `dinuc_shuffle` preserves dinucleotide counts exactly; no sampler or acquisition method uses the global RNG; Slurm caps agree with `sacctmgr`; no (seed, index) overlap across 609 menu directories; exit-75 handling; paired arms use the same pools and seeds; no second strategy table under `albench/`.
